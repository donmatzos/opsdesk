# Ops (draft)
## CI/CD (real: GitHub Actions)
`ci.yml`: on every push and PR only `verify` runs (reusable `maven-verify.yml`: `./mvnw verify`, SonarCloud if `SONAR_TOKEN` exists, one JUnit check "Test report" for TestNG + Vitest). The rest runs only for pushes to `main` (merges; skipped jobs count as passed for required checks): `context-check`, `secrets` (gitleaks, full history), `trivy-fs` (config `trivy.yaml`: npm, secrets, Dockerfile + Helm misconfig; `pom.xml` skipped because of Maven Central rate limits), `helm`, `image` (build, Trivy gate, `tools/ci-smoke.sh` with random UID + read-only FS + per-run DB password), `publish` (only job with `packages: write`; runs on `main` when repo variable `PUBLISH_IMAGE=true` and after `image`, `secrets`, `context-check`; pushes `ghcr.io/donmatzos/opsdesk` without provenance/SBOM manifests so 'keep 10 versions' means 10 pushes). Main runs are never cancelled by concurrency. Trivy results go to GitHub code scanning (SARIF, main only). Gates: HIGH/CRITICAL with a fix. Actions pinned by SHA; Dependabot (maven, npm, actions, docker) bumps them. Fork/Dependabot PRs: no secrets, Sonar skipped, report annotate-only. Because gitleaks and the context check no longer run on PRs, rely on the local pre-commit hook and `python3 tools/context_check.py` before pushing.
`terraform` job: `infra/terraform/datadog` (monitors + dashboard, MOCK) `fmt -check`, `init -backend=false`, `validate`, tflint; never plan/apply. Later: tag releases (jar, image, chart).
## CI templating (mocked: GitLab, Jenkins)
`ci/gitlab/`: one shared template (stages build/test/scan/package/deploy) included by a consumer that sets only variables (thesis topic). `ci/jenkins/Jenkinsfile`: same stages.
## Container (real)
`Dockerfile`: build on `eclipse-temurin:25-jdk-noble` (`-DskipTests`, cache mounts), extract Boot layers (`jarmode=tools`), run on `eclipse-temurin:25-jre-ubi10-minimal` as `1001:0`, `/app` `g=u`, `HEALTHCHECK` via curl. Verified with `--user 123456:0 --read-only --tmpfs /tmp`. `.dockerignore` keeps `.env`, `.git`, `target`, `node_modules` out. `tools/smoke-test.sh <url>` checks health, API, UI. Compose profile `app` runs the image with Postgres; both read passwords from `deploy/compose/.env`.
## Kubernetes / OpenShift (real)
Chart `deploy/helm/opsdesk` (restricted-v2 SCC / PSS restricted, probes, read-only FS, Route or Ingress, NetworkPolicies, values schema). Optional `mcp.tokenSecret` names a Secret with key `token`, injected as `OPSDESK_MCP_TOKEN`; unset = MCP returns 503. Stages: `values-dev.yaml` (demo profile, in-namespace sclorg PostgreSQL with in-cluster generated password kept across upgrades), `values-prod.yaml` (MOCK: external DB Secret, HPA 2-4, PDB). Checks: `tools/helm-check.sh` (CI job `helm`), Trivy renders the chart via `trivy.yaml`, local `tools/kind-verify.sh`. CI `deploy-dev` (main, `OPENSHIFT_DEPLOY=true`, after `publish`): `oc` 5.0.1 from the Red Hat mirror (sha256), `helm upgrade --install --rollback-on-failure`, smoke test on the Route, `helm rollback` on failure. Setup: `deploy/openshift/README.md`.
## Observability (real, Datadog mocked)
Ports: app 8080 (Route/Ingress; probes `/livez`, `/readyz`), actuator 9090 (`/actuator/prometheus`, health; never routed, NetworkPolicy: own namespace only; pod annotations `prometheus.io/*`). Metrics (`metrics/IncidentMetrics`): `opsdesk.incidents.opened{severity}`, `.time.to.resolve{severity}` (timer, SLO buckets 15m/1h/4h/1d/7d; MTTR = sum/count), both pre-registered and recorded after commit; `.active{state}` refreshed from the DB every 15 s (NaN when the DB is down; global value: aggregate with max across replicas). Logs: image writes ECS JSON with `trace.id`/`span.id` and `incident.*`. Local Elastic stack: compose profile `observability` (Elasticsearch, Kibana, Filebeat 9.5.5; security off, 127.0.0.1 only; data stream `opsdesk-logs`), check `tools/elastic-verify.sh [--down]`. Datadog: see `cloud-mocks.md` (registry tags service/env/version from `DD_*`).

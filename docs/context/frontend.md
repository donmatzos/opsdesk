# Frontend (phase 7, done)
Angular 22 workspace in `frontend/`, standalone components, signals, `rxResource` for loading states, no state library. Design and accessibility rules (binding): `docs/guide/design.md`.

## Structure (`src/app/<feature>/`)
`layout/` shell (skip link, sticky header with logo, theme toggle and GitHub icon, sticky full-height sidebar from 1024 px, off-canvas drawer below with scrim/Escape/inert main), `nav-items.ts` (single nav source), `theme.service.ts` + `theme-toggle.ts` (System/Light/Dark, stored, no-flash script in `index.html`), title strategy, focus-on-navigate · `shared/` icon (Lucide paths drawn by the template, not `innerHTML`: the sanitizer strips SVG), status badge (state/status = pill with icon, severity = text tag), relative time, problem helpers · `overview/` (landing: tiles, needs attention, service cards) · `catalog/` · `incidents/` (list with chips, disclosure form, detail with timeline) · `assist/` (examples, `format-answer.ts`, source cards) · `guide/` (Markdown pages with "On this page" rail, glossary cards) · `demo/` (in-browser API mock) · `testing/axe.ts` (spec helper). Shared CSS (cards, tiles, chips, card tables) in `src/styles/_components.scss`. One `*-api.ts` per feature holds the API types and URLs (`assist/assist-api.ts` is the only file that knows the `/api/assist` shape).

## Rules
- **Colours only as CSS custom properties** from `src/styles/_tokens.scss` (palette Indigo; light/dark mixins, dark via OS or `data-theme`); `python3 tools/contrast_check.py` checks every pair (also in CI). No raw hex in components, no `!important`, no click handlers on non-interactive elements (use a stretched link). Tables carry `data-label` per cell and the `table-cards` class so they become card lists below 768 px.
- WCAG 2.2 AA: labelled inputs, errors next to the field with `role="alert"`, results in `aria-live="polite"`, status never by colour alone, one `h1` per page, focus to `main` after navigation, 44 px targets, no emoji icons.
- **New route -> also `SpaForwardController` + `SpaRoutingTest`** (deep-link refresh). Guide pages are listed one by one, never `/guide/*`: the Markdown sources are static files below `/guide/`.
- Components: `inject()`, signals, no `any`; templates > ~30 lines go to a `.html` file.

## Guide (`docs/guide/*.md` -> app)
`scripts/copy-guide.mjs` (npm `pre*` hooks) copies `docs/guide` (md + svg) to `src/generated/guide` (git-ignored), served as assets under `guide/`. Angular rejects asset inputs outside the workspace, hence the copy. `guide/markdown.ts` renders with `marked`: raw HTML dropped, Angular's sanitizer stays on (no `bypassSecurityTrust*`), heading ids set on the DOM afterwards (sanitizer strips `id`), `../../<path>` links -> `<repoUrl>/blob/<ref>/<path>`, `<page>.md` -> `guide/<slug>`. `tools/guide_check.py` checks relative links and glossary `Source:` lines (CI `context-check` job). External glossary URLs were checked once with curl; the three docs.redhat.com ones answer 403 to bots and are unverified.

## Demo mode and Pages
`ng build --configuration demo` (`npm run build:demo`) swaps `environment.ts` for `environment.demo.ts` (`demo: true`, home route `guide`) and registers `demoApiInterceptor`: every `/api/*` request is answered by `DemoBackend` (fictional data, real rules: forward-only transitions, 400/404/409/422 problem details, mock assistant). The jar build registers no interceptor. `.github/workflows/pages.yml` builds with `--base-href /<repo>/`, copies `index.html` to `404.html` (deep links), runs `tools/pages-a11y.sh` (puppeteer + axe-core instead of the planned pa11y-ci, so colour scheme emulation is exact: 11 routes x light/dark x desktop/phone, open drawer, forced theme through the toggle incl. reload, and the sticky-sidebar measurement on a long page) and deploys when `PAGES_DEPLOY=true`.

# UI rework (branch `update/ui-rework`)

**Why:** owner review of the phase 7 UI (screenshots 2026-11-11): the sidebar does not reach the bottom and scrolls away on long pages, no theme toggle, no real overview, flat visual language, forms before lists, raw assist answers, clipped tables on phones, long single-column glossary. Full findings: `docs/guide/design.md` (section "Rework analysis", written in task 9).

**Decisions (owner, 2026-11-11):** theme control System / Light / Dark (stored, no flash); new Overview page as dashboard landing; new palette **A "Indigo"** (all pairs contrast-checked, `tools/contrast_check.py`); one branch, task by task.

## Constraints
Same as phase 7: tokens only (no raw hex), WCAG 2.2 AA (axe in specs, `tools/pages-a11y.sh` on the built site, light + dark, desktop + phone), every new route in `SpaForwardController` + `SpaRoutingTest`, API types only in `*-api.ts`, `./mvnw verify` green before each commit, no Sonar suppressions without the owner (see `conventions.md`).

## Tasks (one commit each)
1. **Tokens and theme:** palette A with layered surfaces (`--surface-2`, soft status tints, `--strong` border for controls), `data-theme` override of `prefers-color-scheme`, `ThemeService` (system/light/dark, localStorage), no-flash script in `index.html`, `ThemeToggle` (radio group), `contrast_check.py` for the new tokens.
2. **Shell:** sticky header (logo mark, toggle, icon GitHub link), sticky full-height sidebar with its own scroll, footer text moved into the sidebar, phone drawer (scrim, Escape, closes on navigation, `inert` main).
3. **Shared UI:** pill state badges and tag-shaped severity badges (distinct), cards, tiles, filter chips, responsive tables as cards below 768 px.
4. **Overview page** (`/overview`, new landing in the jar): status tiles, needs-attention incidents, service cards.
5. **Services and incidents:** list first, chips with counts, clickable rows, relative times, "Open incident" as a disclosure panel, detail page as card + timeline.
6. **Ask the runbooks:** example chips, formatted answer card, mock badge once, source cards.
7. **Guide and glossary:** "On this page" rail, glossary cards with sticky letter rail, diagram label fix.
8. **Checks:** extend `pages-a11y` (toggle forces each scheme, drawer open), specs for all new parts.
9. **Docs:** `design.md` (analysis + new system), `frontend.md`, `status.md`.
